# Smart Energy Management System

A full-stack smart energy management dashboard for monitoring buildings, departments, consumption, reports, and system settings.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS, Chart.js
- Backend: Flask, SQLAlchemy, JWT
- Database: MySQL

## Project Structure

- `frontend/` - React dashboard application
- `backend/` - Flask API application
- `database/` - MySQL schema

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Demo login:

```text
admin
admin123
```

## Backend

```bash
cd backend
pip install -r requirements.txt
python run.py
```

Create the database using `database/schema.sql` before running the backend.
